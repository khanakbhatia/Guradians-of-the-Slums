# Demo Data

Synthetic demo fixtures for the Guardians of the Slums AI service.

These records are realistic but not real incident records. They are designed for hackathon demos using Indian informal-settlement scenarios across Mumbai, Delhi, Kolkata, and Bengaluru.

## Files

- `satellite_outputs.json`: computer-vision-style outputs for dense settlements
- `citizen_reports.jsonl`: cleaned citizen incident reports
- `weather.json`: recent weather and rainfall observations
- `flood_events.json`: historical flood event records
- `road_closures.json`: blocked and degraded roads
- `volunteers.json`: volunteer matching inputs
- `authorities.json`: authority and NGO coordination contacts
- `shelters.json`: shelters for evacuation planning
- `graph_input.json`: road, building, drainage graph input
- `resource_allocation_input.json`: resource allocation input
- `evaluation_sample.json`: small benchmark sample for evaluation pipeline
